# 部門計数ビジュアライザ

部門の計数状況(元帳データ)を手軽に眺めるための、**単一 HTML ファイルで完結する**軽量ツールです。
インストール・ビルド・サーバー不要。`index.html` をブラウザで開き、元帳ファイルを読み込むだけで動きます。
データはすべてブラウザ内で処理され、端末の外には出ません。

## 使い方

1. `index.html` をブラウザで開く(PC / Android どちらでも可。file:// のままで動きます)
2. 「ファイルを選択」ボタン(またはドラッグ&ドロップ)で元帳ファイルを読み込む
   - 複数ファイルを一度に選択できます。**1 ファイル = 1 断面**として扱われます
   - **「複数ファイルを1断面に結合」**にチェックを入れて複数ファイルを選ぶと、それらを合算した
     1 つの断面として読み込みます(事業元帳+販管費元帳のように分かれている場合用。
     列構成の差は自動吸収し、同一キーの行は数値を合算)
   - まず動きを見たいときは「デモデータを読み込む」ボタンで組み込みのサンプルが入ります
3. タブでビューを切り替える
   - **全体表**: 断面を 1 つ選び、表示列の選択・行フィルター・ソート。表示中の行だけの小計行が出ます
   - **推移グラフ**: 指標とプロジェクトを選んで折れ線表示。年月推移(1 断面内)と断面間推移の 2 モード
   - **断面比較**: 前回/今回の 2 断面を突合し、追加・削除・値変化のあった行を抽出表示。
     状態バッジ(追加/削除/変更/変化なし)をクリックして絞り込み、表示列選択・行フィルターも可能。
     表示中の行だけを集計したサマリ表(前回計/今回計/増減)が詳細表の上に出ます
4. 表の「固定列」セレクターで、横スクロール時に左端から何列を固定表示するかを変更できます
   (デフォルト: 全体表 2 列、比較表 4 列。スマホ幅では最大 2 列)

## 対応する元帳ファイル

| 形式 | 説明 |
|---|---|
| CSV | 文字コードは CP932(Shift_JIS)/ UTF-8 を自動判定 |
| 偽 xls | 拡張子 .xls だが実体が HTML の表(業務システム出力)。`<table>` をパース |

判定は拡張子ではなく**内容**で行うため、拡張子が実体と食い違っていても読めます。

### データの前提

- 行は基本的に **年月(yyyymm)× プロジェクトコード** で一意
- 同一キーの行が複数ある場合(例: 販売費および一般管理費が 2 行に分かれるケース)は、
  **数値列を自動で合算**して 1 行に統合します(合算された行は件数を保持し、警告として確認できます)
- 数値は `1,234,000` のカンマ区切り、`△` / `▲` / `(1,234)` の負数表記、全角数字も解釈します
- キー列(年月・プロジェクトコード)は列名の候補リスト(`index.html` 冒頭の `CONFIG`)で自動検出します。
  **実データで列名が異なる場合は `CONFIG` の候補リストに列名を足すだけで適合できます**

### CONFIG による調整(`index.html` 冒頭)

| キー | 用途 |
|---|---|
| `keyColumns` | キー列(年月・プロジェクトコード)の列名候補 |
| `projectNameColumns` | プロジェクト名として表示に使う列名候補 |
| `forceDimColumns` | **数値に見えても文字列として扱う列名**(受注番号などのコード類。合算・集計対象から外れる) |
| `ignoredColumns` | **取り込み時に列ごと無視する列名**(元帳内の「販管費計」のような冗長な小計列など) |

## 実データの取り扱い(重要)

**実データはこのリポジトリにコミットしません。**

- 実データは `data/` ディレクトリに置いてください(`.gitignore` で git 管理外にしてあります)
- ルート直下の `*.csv` / `*.xls` / `*.xlsx` も保険で除外済みです
- リポジトリにコミットするのは `sample-data/` のダミーデータのみです

## ダミーデータ

`sample-data/` に検証用のダミー元帳が入っています。`generate_dummy.py`(Python 標準ライブラリのみ、シード固定)で再生成できます:

```bash
python3 sample-data/generate_dummy.py
```

- `ledger_202506締め.csv` … 断面 A(CP932)
- `ledger_202507締め.csv` … 断面 B(CP932)。断面 A との差分を仕込み済み(追加 7 / 削除 1 / 変更 1)
- `ledger_202506締め_utf8.csv` … 断面 A の UTF-8 版(エンコード判定の検証用)
- `ledger_202507締め.xls` … 断面 B の偽 xls 版(カンマ区切り数値・△負数入り)
- `ledger_202507締め_A事業.csv` / `_B販管費.csv` … 断面 B を事業元帳/販管費元帳に分割した 2 ファイル
  (「複数ファイルを1断面に結合」の検証用。結合すると `ledger_202507締め.csv` と同じ断面になる。
  B 側の「販管費計」列は `ignoredColumns` の検証用)

## 開発メモ

- 依存ライブラリゼロ(バニラ JS + 手書き SVG グラフ)。`index.html` 1 ファイルにすべて入っています
- ファイル内は「CONFIG → util → parsers → model → compare → chart → views → app」の
  レイヤー構造で、下位レイヤーは DOM に依存しません
- 純関数レイヤー(パース・正規化・合算・比較)の回帰テスト:

```bash
node test/run-tests.mjs
```
